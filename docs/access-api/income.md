# 收入记录与收支统计（1.4.8+23，已部署）

Flutter 饮食消费页面新增收入录入与明细；原有餐食、其他消费继续保存到原表。账号身份由 Bearer 会话确定，客户端不能提交 user_id。

## 接口

| 方法与路径 | 功能 |
| --- | --- |
| `GET /incomes?start=2026-10-01&end=2026-10-31` | 查询当前账号指定时间范围的收入，按日期、编号倒序返回；范围最多一年 |
| `POST /incomes` | 创建一笔收入，同一天允许多笔 |
| `PUT /incomes/{id}` | 编辑当前账号的收入，可调整日期、分类、金额、备注 |
| `DELETE /incomes/{id}` | 删除当前账号的收入；不存在或无权访问返回 404 |

创建请求示例（金额单位为分）：

```json
{
  "date": "2026-10-17",
  "category": "兼职",
  "income_cents": 128050,
  "notes": "周末兼职",
  "client_request_id": "0123456789abcdef0123456789abcdef"
}
```

日期限 2000-01-01 至北京时间当天。金额为严格整数分，范围 1–10,000,000,000 分，不能传负数、浮点数或布尔值。分类为非空文本（最多 80 字符），备注选填（最多 1000 字符）。客户端提供工资、奖金、兼职、红包、其他收入五个常用分类。

创建返回 `id`、`date`、`category`、`income_cents`、`notes`。编辑提交同样字段，去掉 `client_request_id` 与 `id`。查询返回上述记录数组。

同一账号重复发送相同的创建请求编号和内容，返回同一记录；编号相同但内容不同返回 409。原始请求摘要在后续编辑中保留，旧创建请求重试不会再次记账或覆盖编辑结果。网络结果不明时，客户端锁定原输入并保留编号用于重试；关闭表单会刷新服务器记录确认结果。

## 页面与统计规则

- 选定记录日期后展示当天的收入、支出、结余，以及当天收入、餐食和其他消费明细；收入可在编辑时选择历史日期。
- 统计支持日、周、月，周一为一周开始，月按自然月；无论哪种范围，柱状图始终按天归集。
- 每个日期收入在零线上方，支出在下方，两者共用最大绝对金额刻度，不是将支出金额保存为负数。
- 每个柱端始终展示具体金额，窄屏和月视图横向滚动；点击、悬停可查看完整日期及收支。过去无记录日期显示零，未来日期显示破折号，不计作零消费。
- 饼图可在收入/支出构成间切换，跟随同一统计范围，展示分类金额、百分比和合计；点击扇区或图例高亮对应分类。
- 结余＝所选范围收入－支出，只代表期间净额，不是账户余额。所有金额先按整数分聚合，再格式化显示。
