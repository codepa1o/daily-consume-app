# 微信小程序

此目录是与 Flutter 客户端、FastAPI 服务端并列的原生微信小程序工程，使用微信开发者工具内置的 TypeScript 编译器。工程按原生小程序能力重做页面和交互，不依赖 Flutter WebView 或跨端框架。

## 功能覆盖

- 账号：用户名登录/注册、微信快捷登录与绑定、资料和头像、隐私说明、版本说明、退出登录。
- 日常记录：体重/身高/目标体重、三餐与其他消费、训练计划与打卡、月历日记/备忘/待办、女性健康周期、番茄钟与记录。
- AI 与研究：聊天会话/流式回答/附件、每日总结与个人分析、论文检索和 PDF 管理、技能代理对话/知识库/评测/诊断。
- 关系与出行：情侣空间、邀请和回忆相册/互动效果、冲突记录与共同约定、AI 行程规划/地图/地点/路线/文本导出。
- 数据迁移：Flutter 客户端可将本机记录导出为 JSON，经微信聊天发送；小程序选取文件、预览记录数量并导入当前账号。

各页面直接调用现有 FastAPI 接口；新增微信身份关联和可选番茄钟订阅提醒的服务端实现见 `server/` 与 Alembic 迁移。

## 开发

1. 在微信开发者工具中导入本目录。
2. `project.config.json` 已配置正式 AppID `wxdd91816241715da2`。之前的 `wx956e9387a6ae29a6` 为测试号，不能用于正式发布；开发者工具登录的微信须有正式账号的开发权限。
3. 将 `config.ts` 中的 API 地址换成已配置 HTTPS 和小程序服务器域名的正式 API 地址。
4. 服务端配置 `WECHAT_MINIPROGRAM_APPID` 和同一正式小程序账号的 `WECHAT_MINIPROGRAM_APPSECRET`，不能沿用测试号的密钥，不得把密钥写入小程序工程。
5. 在小程序后台登记 HTTPS `request` 域名；回忆照片和论文文件使用 `downloadFile`，也需要登记下载域名。
6. 按实际功能声明隐私保护指引，至少覆盖账号资料、照片/视频、聊天文件和女性健康记录。
7. 部署服务端前运行 `alembic upgrade head`，创建微信身份关联和番茄钟提醒表。
8. 按需关闭开发者工具的域名校验，仅用于本地联调；体验版和正式版必须配置服务器域名。

如需番茄钟后台订阅提醒，还需在微信公众平台创建并审核一次性订阅模板，将模板 ID 同时填入 `config.ts` 的 `POMODORO_SUBSCRIBE_TEMPLATE_ID` 和服务端 `.env` 的 `WECHAT_POMODORO_TEMPLATE_ID`；按模板字段配置 `WECHAT_POMODORO_TEMPLATE_FIELDS`。用户拒绝订阅时，前台计时仍可使用。

安装 npm 依赖后，可运行 `npm run typecheck` 检查 TypeScript 类型。

编译和真机联调前还需要配置正式 HTTPS API 域名、服务器域名白名单、隐私保护指引，以及服务端微信密钥。番茄钟后台提醒属于可选能力；没有审核通过的订阅模板时，小程序仍可使用前台计时。
